# EgoEMG data card placeholder

The current EgoEMG dataset is **not released** with code pre-release `0.1.0rc1`.
Accordingly, this file deliberately does not make claims about data access,
subject consent, privacy processing, sample counts, splits, annotation quality,
or permitted use that have not yet been verified for publication.

Before a data release, replace this placeholder with a reviewed data card that
includes the following.

- Collection protocol, participating populations, modalities, and time range.
- Consent/ethics basis, privacy and de-identification process, and handling of
  egocentric video and physiological signals.
- Dataset schema, annotation procedure, quality controls, splits, and known
  biases or failure modes.
- Intended and prohibited uses, access controls, redistribution rules, contact
  channel, and withdrawal/correction process.
- Data version, license, release manifest, integrity checksums, and compatibility
  with each published model checkpoint.

Legacy material is not covered by this placeholder and must not be represented
as the forthcoming EgoEMG release.
